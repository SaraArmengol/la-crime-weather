## 1. Map notebook cells to modules
Go through the Colab notebook cell by cell and move each piece of logic into a function:

| If the cell... | It goes in |
|---|---|
| downloads/reads crime data | `extract/lapd.py` |
| calls the weather API | `extract/weather.py` (keep the caching pattern) |
| scrapes with BeautifulSoup | `extract/scrape_stats.py` → `parse_table` |
| cleans or fixes crime columns | `transform/clean_crime.py` |
| merges, aggregates, creates features | `transform/features.py` |
| makes a chart for the write-up | `notebooks/02_findings.ipynb` (imports from `src/`) |

Rules: functions take DataFrames in and return DataFrames out; no global variables; no file paths hard-coded (use `config/settings.yaml`).
